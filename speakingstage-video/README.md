# SpeakingStage – Speaker-Recruiting-Video (9:16)

Motion Graphic (30 s, 1080×1920) für `speakingstage.com/speaker-werden`, gebaut mit [Remotion](https://github.com/remotion-dev/remotion).

- `npm i` – Abhängigkeiten installieren
- `npm run audio` – Musik und SFX synthetisch erzeugen (`scripts/make-audio.mjs`, getaktet auf `src/timing.json`)
- `npm run studio` – Vorschau im Remotion Studio
- `npm run render` – Video nach `out/speakingstage-speaker.mp4` rendern

Fertiges Video: `speakingstage-speaker.mp4`
