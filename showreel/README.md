# Lucy Larbi – Showreel (SpeakingStage CI)

- `lucy-larbi-showreel.mp4` – fertiger Reel, 1080p, 35,5 s, mit Musik
- `reel.html` – Motion-Engine (Canvas, alles = Funktion der Zeit). Per lokalem Server öffnen (`python3 -m http.server`), Klick = Start mit Ton.
- `tools/` – Musik-Synthese (`synth.py`) und Frame-genauer Export (`render.js`, Playwright + ffmpeg)
- CI: Navy #162131, Kupfer #a7643c, Creme #f7f3ee. Medien von speakingstage.com und lucylarbi.de (Nutzungsrechte der Logos/Fotos vor Veröffentlichung prüfen).
